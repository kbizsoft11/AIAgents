01

Getting started

ColixAI expands a short trigger into a longer piece of text. Open the dashboard, create a shortcut, and give it a memorable trigger such as /sig or /thanks.

1Click New Shortcut.
2Add a label, trigger, and content.
3Save, then type the trigger on a webpage.
02

Shortcuts

Use the left sidebar to browse your snippets and folders. Select any snippet to edit it in the center editor. A shortcut can contain plain text, multiple lines, or formatted content.

  • Label: the name you see in the dashboard.
  • Shortcut: the trigger you type, for example /intro.
  • Content: the text or formatted message ColixAI inserts.
03

Dynamic fields

The right command panel lets you insert values that are filled when the shortcut is used. Add them at the cursor position in the editor.

Aa

Text fieldOne-line value with an optional default.

≡

Paragraph fieldMulti-line text area for longer answers.

⌄

Dropdown and radioLet the user choose from prepared options.

∑

FormulaEvaluate basic numeric expressions such as 7 * 8.

▣

Clipboard and Date/TimeInsert the latest copied text or a selected date/time format.

When a shortcut contains fields, ColixAI opens a small native window. Fill in the values and select Insert to continue.

04

Formatting and emojis

Use the simple editor toolbar for bold, italic, underline, lists, and line breaks. The emoji button opens the emoji collection; choose an emoji to add it where the cursor is placed.

05

Using shortcuts on webpages

Click inside a text input, textarea, or supported editor and type your trigger. ColixAI replaces the trigger with the saved content. You can also open the floating ColixAI icon to browse and insert a shortcut.

TipKeep triggers short and unique. A leading slash, such as /reply, makes them easy to remember.
06

Account and sync

Your shortcuts are stored in the extension and can be synchronized for your signed-in account through the connected Supabase service. Keep the extension signed in if you want account data and shortcut changes to stay available across supported sessions.
