How to Use ColixAI

1

Create a Shortcut

Click "New Shortcut" and set a trigger like -hbd and the text it should expand to.

2

Type Anywhere

Go to any website and type your trigger in any text field, textarea, or editable area.

3

Instant Expansion

Your shortcut is instantly replaced with the full text. No extra keys needed!

Tips

  • Start triggers with - / ; or ! to avoid accidental triggers
  • Type // in any field to open the shortcut picker menu
  • Use {{first_name}}, {{last_name}}, {{email}} for dynamic tokens
  • Use multi-line text for email templates and signatures
  • Triggers are case-sensitive: -HBD ≠ -hbd
