START HERE

ColixAI basics

ColixAI turns a short trigger into a saved piece of text. Create a shortcut once, then use it in supported text fields across the web whenever you need it.

Open the dashboard and select New Shortcut. Add a label, trigger, and expansion text, then save it. Your shortcut appears in the sidebar and is ready to use.

Click a supported text input and type the shortcut trigger. ColixAI replaces the trigger with its saved content. You can also use the floating ColixAI control to browse your shortcuts.

03

MAKE IT FLEXIBLE

Dynamic fields

Dynamic fields let you fill in changing details when a shortcut is used. ColixAI supports text, paragraph, dropdown, radio, formula, clipboard, and date/time fields.

ColixAI opens a small input window before inserting the completed text. Fill in the requested values and select Insert to continue.

04

YOUR WORKSPACE

Account and sync

Your shortcuts are stored in the extension and can be synchronized for your signed-in account through the connected Supabase service.

Make sure you are signed in with the same account and give sync a moment to complete. Reopen the dashboard if the latest changes are not visible.
